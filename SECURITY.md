# Política de seguridad

## Versiones compatibles

| Versión | Soporte |
|---|---|
| 1.0.x | Sí |
| < 1.0 | No |

## Informar de una vulnerabilidad

No publiques información sensible en una incidencia. Utiliza el apartado
**Security > Report a vulnerability** del repositorio para enviar el informe de
forma privada:

<https://github.com/Roger08G/scopeth/security/advisories/new>

Incluye la versión afectada, el entorno, los pasos mínimos para reproducir el
problema y su impacto. No adjuntes claves privadas, tokens, contratos privados ni
datos obtenidos sin autorización.

Se confirmará la recepción cuando el canal privado esté disponible. La
investigación, corrección y publicación se coordinarán antes de divulgar detalles.

## Alcance del proyecto

Scopeth realiza análisis estático local. No ejecuta explotación, no consulta estado
on-chain de forma implícita y no debe utilizarse como única base para afirmar que un
contrato es seguro o vulnerable.
